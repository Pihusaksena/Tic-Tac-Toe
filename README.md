# 🎮 Tic Tac Toe Game

A simple and interactive **Tic Tac Toe** game built using HTML, CSS, and JavaScript. This project allows two players to play the classic Tic Tac Toe game in a clean and colorful interface.

## ✨ Features

- Two-player gameplay (Player O and Player X).
- Interactive 3×3 game board.
- Automatic winner detection.
- Displays a congratulatory message when a player wins.
- Reset Game option to restart the game.
- New Game option to start a fresh match.
- Simple and user-friendly interface.

## 🛠️ Technologies Used

- **HTML5** – Structure of the game.
- **CSS3** – Styling and layout.
- **JavaScript** – Game logic, player turns, and winner detection.

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/Pihusaksena/Tic-Tac-Toe.git
   ```

2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start playing!

## 🎯 How to Play

1. The game starts with Player O.
2. Players take turns selecting an empty box.
3. The first player to get three marks in a horizontal, vertical, or diagonal line wins.
4. Click **Reset Game** or **New Game** to restart.
